## 🧭 What I work on

Pashto is mostly typed in Roman letters online, with no standard spelling, and few reliable datasets, tokenizers, or lexicons exist for it. I work from those foundations (romanization, normalization, data quality) up through models (language detection, sentiment analysis) to **deployable AI systems** (APIs, RAG pipelines, LLM assistants).
